# P4.4 Region locator, safe click area and position-only sampler (R07, R13)

[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M4](../milestones/M4.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

Read [execution rules](../execution.md) and [safety invariants](../safety.md) before executing. Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. Follow linked dependencies for their contracts; execute only this packet.

- **Outcome**: an explicitly authored window-relative region locator plus a rectangular safe area relative to a fixed/region/image/text target, with exclusions. Fixed/region locators still require fresh source/geometry and current recipient checks; they do not claim to follow a moved visual object. Integer points are sampled by scanline intervals using a recorded seed and re-validated after quantization. Variation is off until the user confirms an area. Timing never varies.
- **Depends on**: [P1.3](P1.3.md).
- **Files**: `packages/geometry/{src/safe-area.ts,src/sampler.ts,test/*.property.test.ts}`, `packages/schema/src/workflow.ts`, `packages/engine/src/locators/region.ts`.
- **Steps**: add the explicit region schema/locator, then transform and integer-containment checks. Write property tests for exclusions, empty geometry and seed replay. Wire the engine and editor preview to the same sampler; when variation is off, validate the deterministic point under the same containment rule.
- **Contracts/errors**: `E_EMPTY_SAFE_AREA`.
- **Acceptance**: `m4.geometry.*`, plus fixture receipts inside the safe area across 200 runs.
- **Artifacts**: point clouds.
- **Out of scope / escalate**: arbitrary polygon editing; rectangular exclusions and transformed/quantized containment are still required.
