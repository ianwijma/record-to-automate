# P2.4 Engine host: run, pause, resume, stop, explanation and run record

[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M2](../milestones/M2.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

Read [execution rules](../execution.md) and [safety invariants](../safety.md) before executing. Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. Follow linked dependencies for their contracts; execute only this packet.

- **Outcome**: the main process can run a saved revision in the utility process with explicit pause, resume and stop. Each run writes a run record pinned to that revision.
- **Depends on**: [P2.1](P2.1.md), [P2.2](P2.2.md), [P2.3](P2.3.md).
- **Files**: `packages/engine/src/host.ts`, `packages/engine/src/run.ts` (accepts schema v1-dev), `packages/engine/src/preflight.ts`, `packages/store/src/runs.ts`, `validation/cases/m2/run.ts`, `native/x11/guard/guard.c`, `packages/host-protocol/src/guard.ts`.
- **Steps**:
  1. Preflight: the document is runnable, the target window resolves to exactly one, the guard is armed for this lease (S1), and no other lease exists. The result is `Ready` or `Blocked{reasons}`.
  2. Run: snapshot the saved document/referenced assets and record `revision` plus its hash, then execute as in [P0.6](P0.6.md) or [P1.3](P1.3.md). Write `runs/<runId>/{run.json, journal.jsonl, frames}`.
  3. Pause: guard `STOP mode=pause`, then park. Resume repeats preflight under a new lease and epoch, takes a fresh observation, and never reuses earlier permits. If pause interrupted an in-flight occurrence or its acknowledgment/settle is unknown, mark it `OutcomeUnknown` and terminal. Only a pause between known-complete occurrences may resume. Stop is terminal. Add bounded key down/up under the same generation/freshness rules; check current focus before each new key injection and block a changed keymap.
  4. Stop explanation: `{stepIndex, stepLabel, expected, observed: frameAsset, outcome, dispatched}`.
- **Contracts/errors**: run events `RunStarted`, `StepStarted`, `StepResult`, `Paused`, `Resumed`, `Stopped`, `Aborted`, `OutcomeUnknown`. `OutcomeUnknown` is terminal: dismissing the message grants no authority to resume, skip or retry. The user may inspect and explicitly start a new run; it gets a new identity and fresh preflight.
- **Acceptance**: `bun run validate --case m2.run.*,m2.guard.recipient-focus`.
  - `m2.run.pause-resume-new-epoch`: an old permit is rejected after resume.
  - `m2.run.stop-mid-click` and `m2.guard.recipient-focus` (focus stolen before key injection → `E_RECIPIENT`, no key receipt).
  - `m2.run.unknown-blocks-resume`.
  - `m2.run.pinned-revision`.
- **Artifacts**: run directories.
- **Out of scope / escalate**: recovery blocks and pause-for-help ([P6.3](P6.3.md)). Basic-mode product retention waits for D-RETAIN; preview diagnostics follow [shared §2](../defaults.md).
