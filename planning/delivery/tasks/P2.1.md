# P2.1 Electron shell, IPC and helper supervision

[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M2](../milestones/M2.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

Read [execution rules](../execution.md) and [safety invariants](../safety.md) before executing. Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. Follow linked dependencies for their contracts; execute only this packet.

- **Outcome**: `bun run dev` opens a dark window that lists helper status. The main process supervises separate modes of the single host binary, starting observe only when recording exists, and runs the engine in a utility process.
- **Depends on**: [P0.6](P0.6.md). The runnable M0 cases pass; faults and attendance add evidence separately.
- **Files**: `apps/desktop/{package.json,vite.config.ts,build.ts,main/src/index.ts,main/src/supervisor.ts,main/src/ipc.ts,main/src/lease.ts,main/src/abort.ts,preload/src/index.ts,renderer/index.html,renderer/src/main.tsx,renderer/src/App.tsx,renderer/src/styles.css,renderer/tailwind.config.ts}`, `packages/engine/src/host.ts` (utility-process entry), `validation/cases/m2/shell.ts`.
- **Steps**:
  0. `apps/desktop/build.ts` bundles main and preload with `bun build --target node --external electron`; Vite builds the renderer. `bun run dev` runs both, then `electron apps/desktop`.
  1. Configure `BrowserWindow` with `sandbox: true`, `contextIsolation: true` and `nodeIntegration: false`. Set the CSP `default-src 'self'; img-src 'self' r2a-asset:`, block navigation, and deny `window.open`.
  2. Preload exposes only the typed `window.r2a` API listed under Contracts. Main validates every payload and rejects unknown fields.
  3. Supervisor: spawn the helpers with fd 3 as the guard's abort pipe, owned by main. `r2a.abort()` writes to that pipe directly and does not go through the engine. Restarting a helper revokes any lease.
  4. `LeaseManager` holds at most one lease, `record` or `run`. Acquiring one while another exists returns `E_LEASE_BUSY`.
  5. Copy the named CSS design tokens from `planning/design/journey.html` into the Tailwind theme, and use the type scale from [DESIGN [shared §4](../../DELIVERY-PLAN.md)](../../design/DESIGN.md#4-visual-hierarchy).
- **Contracts/errors**: the API is `listWindows()`, `listWorkflows()`, `getWorkflow(id)`, `saveRevision(id, baseRev, doc)`, `startRecording(windowRef)`, `pauseRecording()`, `resumeRecording()`, `stopRecording()`, `preflight(id)`, `run(id)`, `pauseRun()`, `resumeRun()`, `stopRun()`, `abort()`, `onEvent(cb)`, `assetUrl(handle)`. Not-yet-integrated operations return `E_NOT_IMPLEMENTED` and stay disabled until their owner packet lands; never fake success to make the shell pass. Errors are `{code, message, details}` with codes `E_VALIDATION`, `E_LEASE_BUSY`, `E_CONFLICT`, `E_NOT_FOUND`, `E_HELPER_DOWN`.
- **Acceptance**: `bun run validate --case m2.shell.*`.
  - `m2.shell.security`: the renderer has no `require` or `process`, navigation is blocked, and an unknown IPC field is rejected.
  - `m2.shell.abort-bypass`: with the engine utility process SIGSTOPped, `abort()` still produces `ABORTED routes=pipe`.
  - `m2.lease.exclusive`.
- **Artifacts**: Playwright trace and helper logs.
- **Out of scope / escalate**: packaging and auto-update.
