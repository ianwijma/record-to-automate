# P6.5 Evidence and storage failures

[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M6](../milestones/M6.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

Read [execution rules](../execution.md) and [safety invariants](../safety.md) before executing. Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. Follow linked dependencies for their contracts; execute only this packet.

- **Outcome**: disk-full, EIO and slow-write checks against the selected D-PREDISPATCH/D-RETAIN policy. A known pre-dispatch required-evidence failure prevents input. A post-dispatch failure stops with incomplete evidence and `OutcomeUnknown` where effect cannot be established; do not erase a known result or invent evidence. Restart detects incomplete traces and never resumes input automatically.
- **Depends on**: [P6.2](P6.2.md).
- **Files**: `validation/lib/faultfs.ts` (injectable storage adapter throwing real-shaped EIO/ENOSPC and delays; separate integration fault cases on a disposable unprivileged filesystem).
- **Steps**: inject each fault and check each outcome.
- **Contracts/errors**: no silent continuation that weakens the selected evidence contract.
- **Acceptance**: `m6.faults.*`.
- **Artifacts**: fault logs.
- **Out of scope / escalate**: if an unprivileged injection method is not workable, escalate.
