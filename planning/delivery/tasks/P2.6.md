- **Outcome**: a minimal version of [board 02](../../design/journey.html#b02). The user presses the abort chord once, and the app records "tested on your setup" for this session. Run preflight requires the current-session test.
- **Depends on**: [P2.5](P2.5.md).
- **Files**: `apps/desktop/renderer/src/pages/Setup.tsx`, `apps/desktop/main/src/abort.ts`, `native/x11/guard/guard.c` (test-mode grab emitting `ABORT_TEST` without dispatch).
- **Steps**: add a guard verb `ARM_TEST`. When the chord is received, report it and make no dispatch. Preflight returns `Blocked{abortKeyUntested}` until the test succeeds in this app session.
- **Contracts/errors**: `E_ARM_CHORD` is shown in plain words, for example "Another app already uses this key."
- **Acceptance**: `bun run validate --case m2.setup.abort-test` (synthetic on Xvfb). The physical press is part of [P2.8](P2.8.md).
- **Artifacts**: screenshot and guard log.
- **Out of scope / escalate**: choosing the final key (D-EXEC-Q).
