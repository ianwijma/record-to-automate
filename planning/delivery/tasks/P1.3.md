# P1.3 Engine image locator: one dispatch or none

[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M1](../milestones/M1.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. Follow linked dependencies for their contracts; execute only this packet.

- **Outcome**: the engine runs `locator.kind:"image"` actions: locate on a fresh frame, click the found box's centre plus the stored offset, and stop on any other outcome.
- **Depends on**: [P1.2](P1.2.md), [P0.6](P0.6.md).
- **Files**: `packages/engine/src/locators/image.ts`, `packages/engine/src/run.ts` (dispatch by locator kind), `fixtures/workflows/m1-image.json`, `validation/cases/m1/image.ts`, `validation/milestones.ts`.
- **Steps**:
  1. On each fresh observation, run `locate` within the search area. The point is the box centre plus the offset. The target box must still contain the point after integer quantization, or the result is `Unavailable("point-outside-box")`.
  2. Any outcome other than `Found` stops with `{expected: template, observed: outcome, candidates?, dispatched:false}`.
  3. The request deadline remains derived from capture time; locate time consumes the budget. Register M1 as current when integrating this path; failing cases remain selected. An explicit incomplete-matcher outcome keeps fixed-only progress labelled separately.
- **Contracts/errors**: new stop reasons `NotFound`, `MoreThanOne`, `CouldNotCheck(reason)`. No fallback to `fixed` exists (S7). A test asserts that the `image` locator has no code path that reads stored coordinates.
- **Acceptance**: `bun run validate --suite m1`. Each case is checked against both ledgers.
  - `m1.image.moved`: 30 seeded displacements. Exactly one dispatch each, and `element == target`.
  - `m1.image.absent` and `m1.image.duplicate`: zero dispatch, with the stop reason `NotFound` or `MoreThanOne`.
  - `m1.image.decoy`: the decoy is never clicked.
  - `m1.image.context` and `m1.image.animated`: either a correct click or a typed stop. A wrong click fails the case.
  - `m1.image.no-fallback`: a static check plus a runtime check.
- **Artifacts**: the frame per attempt, the locate result and the ledgers.
- **Out of scope / escalate**: safe-area variation ([P4.4](P4.4.md)).
