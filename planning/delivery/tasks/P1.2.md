# P1.2 Fixture scenes and automatic image-target draft

[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M1](../milestones/M1.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

Read [execution rules](../execution.md) and [safety invariants](../safety.md) before executing. Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. Follow linked dependencies for their contracts; execute only this packet.

- **Outcome**: scenes for the moved-target proof, and `draftImageTarget(preFrame, clickPoint)` with a self-test.
- **Depends on**: [P1.1](P1.1.md), [P0.3](P0.3.md).
- **Files**: `fixtures/x11-target/scenes.c` (new scenes), `packages/vision/src/draft.ts`, `packages/vision/test/draft.test.ts`.
- **Steps**:
  1. Add the scenes, all seeded: `icon-home` (target icon at its recorded position), `icon-moved dx dy`, `icon-absent`, `icon-duplicate`, `icon-decoy` (a similar icon that differs in one quadrant), `icon-context` (background colour and layout change, same icon) and `icon-animated` (animation elsewhere in the window).
  2. `draftImageTarget` crops a 48×48 region centred on the click (clamped), runs `locate` against the source frame over the whole window, and returns the template, its offset from the click and `draftStatus: "ok"`. A self-test that is not `Found` at the source position, or a low-information crop, sets `flagged` with reasons.
- **Contracts/errors**: draft flags are `no-pre-frame`, `low-information`, `not-unique-in-source` and `self-test-moved`.
- **Acceptance**: `bun run validate --case m1.draft.*` on Xvfb, using captured frames of each scene.
- **Artifacts**: template PNGs and self-test results.
- **Out of scope / escalate**: user editing of the crop ([P2.5](P2.5.md), [P4.6](P4.6.md)).
