Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. - **Outcome**: extraction plus guard compound actions that share one action identity and are interruptible.
- **Depends on**: [P2.4](P2.4.md), [P0.5](P0.5.md).
- **Files**: `packages/recording/src/extract.ts`, `native/x11/guard/guard.c` (compound submit with bounded subcommands), `packages/engine/src/actions/*.ts`.
- **Steps**:
  1. Each compound action carries one generation/sequence identity; define allowed bounded subcommands and a duration limit before implementing that action.
  2. Every subcommand re-checks the epoch.
  3. Abort releases the owned holds mid-compound.
- **Contracts/errors**: `E_COMPOUND_TOO_LONG`.
- **Acceptance**: `m4.gesture.*`: the ledger matches each gesture, and abort mid-drag and mid-chord releases exactly the owned inputs.
- **Artifacts**: ledgers.
- **Out of scope / escalate**: compound actions spanning observations.
