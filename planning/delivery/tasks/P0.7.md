# P0.7 Passive observation with in-process target filtering and the event–frame test

[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M0](../milestones/M0.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

Read [execution rules](../execution.md) and [safety invariants](../safety.md) before executing. Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. Follow linked dependencies for their contracts; execute only this packet.

- **Outcome**: the later recording worker `r2a-x11-host --mode observe` emits only target-window input events with server time, mapped time and coordinates, and reports gaps instead of guessing. The early clock and event–frame association test exists.
- **Depends on**: [P0.4](P0.4.md), [P0.6](P0.6.md).
- **Files**: `native/x11/observe/{observe.c,classify.c,classify.h,ring.c,ring.h}`, `packages/host-protocol/src/observe.ts`, `validation/cases/m2/observe.ts`, `validation/cases/m2/event-frame.ts`.
- **Steps**:
  1. Call `r2a_harden()` first.
  2. `START target=<xid> lease=<id>` opens an XRecord context for device events (KeyPress through MotionNotify) on a dedicated data connection. A control connection selects `EnterWindowMask | LeaveWindowMask | FocusChangeMask | StructureNotifyMask` on the target client and tracks a focus and pointer-containment timeline with server times where events carry them.
  3. Classify each raw event in C:
     - Pointer: target if the root point lies inside the target's current root rectangle and the pointer-containment timeline shows the pointer inside the target at that server time. Otherwise non-target.
     - Key: target if the focus timeline shows the target or a descendant focused at that server time.
     - Indeterminate: if the timeline cannot answer (for example, a missing event since the last epoch, an unmatched grab, or a pending FocusIn) the event is indeterminate.
     - Non-target and indeterminate events are zeroed in memory and never printed. Indeterminate events produce `GAP reason=indeterminate count`.
  4. Emit target events as `EV seq type server_ms x y button|keycode state` (window-relative coordinates). The bounded ring holds `observeBufferEvents` events. On overflow, emit `GAP reason=overflow` and drop all events until `RESTART` re-establishes the timeline boundary.
  5. `STOP` closes the context and zeroes the buffers.
  6. Record the candidate method and its known limits in `fixtures/x11-target/README.md`. Its correctness is measured, not assumed.
- **Contracts/errors**: `E_RECORD_UNAVAILABLE`, `E_TARGET_GONE` (followed by a terminal GAP), `E_NOT_LEASED`. The observer runs only while a record lease is open. In these M2 prerequisite tests, the harness grants an exclusive record session; this worker is not started for fixed replay.
- **Acceptance**: `bun run validate --case m2.observe.*,m2.clock.event-frame` on Xvfb.
  - `m2.observe.target-filter`: two fixture windows, A as target and B as non-target. Synthetic typing of sentinel `R2A-SENTINEL-<random>` into B, and clicks in both. Output contains only A's events with matching coordinates. The artifact scan finds no sentinel. B's events are absent and not counted as gaps.
  - `m2.observe.focus-race`: rapid focus flips with typing produce events classified exactly as the fixture ledgers show, or as gaps. Any indeterminate event stops the take; non-target events must not escape even during the race. An all-dropped stream cannot pass useful recording: the stable-target positive case must retain every scripted click/key pair. The case reports counts.
  - `m2.observe.overflow`: run with `observeBufferEvents=8` and a burst → `GAP overflow`, and no fabricated or partial events afterwards until `RESTART`.
  - `m2.clock.event-frame` (measure): a fast move–click–move with a sub-frame click. The observed click coordinates equal the fixture recv coordinates. The mapped event time lies within calibration uncertainty of recv. The case reports which captured frames precede and follow the event using conservative intervals.
- **Artifacts**: observer output (target-only), classification counts, `event-frame.csv`.
- **Out of scope / escalate**: gesture extraction ([P2.3](P2.3.md), [P4.1](P4.1.md)). If classification cannot be made correct on the fixture, report the method as *inconclusive* and propose alternatives (for example XI2 raw events plus a server-side focus query). M2 recording remains blocked; an experimental flag cannot authorize misclassified events. Fixed replay/editor work can continue independently.
