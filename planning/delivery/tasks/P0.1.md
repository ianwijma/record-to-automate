# P0.1 Validation orchestrator

[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M0](../milestones/M0.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

Read [execution rules](../execution.md) and [safety invariants](../safety.md) before executing. Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. Follow linked dependencies for their contracts; execute only this packet.

- **Outcome**: `bun run validate` behaves as specified in [shared §3](../validation.md), with a self-test.
- **Depends on**: [P0.0](P0.0.md).
- **Files**: `scripts/validate/{index.ts,registry.ts,context.ts,prereqs.ts,report.ts,manual.ts,xvfb.ts,scan.ts}`, `validation/cases/env/{toolchain.ts,xvfb.ts}`, `validation/cases/self/{pass.ts,fail.ts,missing.ts,manual.ts}` (tagged `selftest`, excluded from `all`), `validation/manual/README.md`, `validation/milestones.ts`.
- **Steps**:
  1. Parse the command line and resolve the selection. Glob matching is on case IDs; multiple suite names are a union, multiple case selectors are a union, and a suite plus case selector is their intersection. Register bootstrap plus the upcoming milestone’s required case IDs; missing implementations remain visible.
  2. Run cases sequentially with a per-case timeout and process-group kill. Write `result.json` for every case.
  3. Implement the prerequisite probes, Xvfb lifecycle, the artifact scan (a byte search of every created file for `ctx.sentinels`), `--failed`, `--list`, `--repeat` and the summary.
  4. Implement fingerprint/environment-based manual-evidence lookup and the `--attended` flow skeleton. Keep required manual results separate in default automated summaries, with strict explicit-suite exit codes ([shared §3](../validation.md)).
- **Contracts/errors**: exit codes and statuses as in [shared §3](../validation.md).2. Cases must not write outside `ctx.artifactDir` or the temporary directories they register.
- **Acceptance**: `bun run validate --suite selftest` exits 1 and reports the expected status for each self-test case. `bun run validate --case self.pass` exits 0. `--case self.missing` exits 2. `--case nope` exits 2.
- **Artifacts**: `summary.json` and the `last` symlink.
- **Out of scope / escalate**: parallel execution and CI configuration.
