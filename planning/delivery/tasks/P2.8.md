[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M2](../milestones/M2.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. Follow linked dependencies for their contracts; execute only this packet.

- **Outcome**: human evidence that the preview works with ordinary physical input on the actual X11 session, using the fixture only.
- **Depends on**: [P2.7](P2.7.md), [P0.9](P0.9.md) (manual evidence present).
- **Files**: `validation/cases/m2/manual-real-session.ts`, `validation/manual/m2.manual.real-session.md`.
- **Steps**:
  1. Test the stop key on the Setup page physically.
  2. Record by physically clicking three fixture elements and pressing one key, while also physically typing the sentinel into a terminal.
  3. Review/accept supported target drafts, edit one step, save, restart the app, and run.
  4. Press the physical abort chord during a second run.
  5. Confirm the receipts and that no sentinel appears in any artifact.
- **Contracts/errors**: refuses Xvfb.
- **Acceptance**: `bun run validate --case m2.manual.real-session --attended`. `bun run validate --suite m2` then exits 0.
- **Artifacts**: evidence file, ledgers, and the project directory listing.
- **Out of scope / escalate**: any target other than the fixture.
