[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M2](../milestones/M2.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

- **Outcome**: an automated preview loop on Xvfb that covers record, edit, save, reload and run.
- **Depends on**: [P2.6](P2.6.md).
- **Files**: `validation/milestones.ts`, `validation/cases/m2/e2e.ts`, `validation/lib/electron.ts`, `validation/lib/driver.ts` (the synthetic user, built on `xdotool` and labelled synthetic).
- **Steps**: register M2 as the current runnable milestone and script each case through Playwright and the synthetic driver. Fix one observed failure, rerun it, then rerun the default loop.
  - `m2.e2e.fixed`: record three clicks on `grid`, review/accept the supported target drafts, change step 2 to Fixed at a different element, save, quit, relaunch, run. The receipts show the edited element.
  - `m2.e2e.image-moved`: record a click on `icon-home`, explicitly accept the target draft and save, switch the scene to `icon-moved`, run. One click lands on the target.
  - `m2.e2e.absent-stops`: run against `icon-absent`. Board 12 state appears, and both ledgers show zero dispatch.
  - `m2.e2e.stop`: Stop during a run. No receipts after the stop.
  - `m2.e2e.reload-identical`: the saved document and assets reload with equal content; the run snapshot hash matches the saved document, including the edited action.
- **Contracts/errors**: none new.
- **Acceptance**: `bun run validate --case m2.e2e.*`.
- **Artifacts**: Playwright traces, ledgers and store trees.
- **Out of scope / escalate**: real-session behaviour ([P2.8](P2.8.md)).
