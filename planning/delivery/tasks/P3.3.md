# P3.3 Check and branch core

[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M3](../milestones/M3.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

Read [execution rules](../execution.md) and [safety invariants](../safety.md) before executing. Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. Follow linked dependencies for their contracts; execute only this packet.

- **Outcome**: `if` and `else` steps with a screen check (image or text present, text equals). False, true and unknown are distinct, and an unknown result goes to the stop policy.
- **Depends on**: [P3.2](P3.2.md); D-BRANCH before branches may authorize desktop mutations. Pure evaluate/select/join tests can run before that choice.
- **Files**: `packages/schema/src/flow.ts`, `packages/engine/src/branch.ts`, `validation/cases/m3/branch.ts`.
- **Steps**:
  1. Implement the common core: evaluate the check on a fresh observation, select an arm, and require every action in the arm to locate its own target on its own fresh observation (S2).
  2. Implement whichever D-BRANCH option the user selects: look-once, or reselection before the arm's first desktop mutation (the DecisionScope rule in [implementation plan §6.1](../../IMPLEMENTATION-PLAN.md#61-outcomes-and-evidence-lifetime)).
  3. Until D-BRANCH is decided, allow read-only branch evaluation only. Branching workflows cannot dispatch input; mutation-dependent cases return `missing: decision D-BRANCH`. A feature flag is not approval of look-once or reselection.
- **Contracts/errors**: `CouldNotCheck` is never treated as false.
- **Acceptance**: `m3.branch.both-paths`, `m3.branch.unknown-stops` and `m3.branch.join`, plus the D-BRANCH-dependent cases `m3.branch.late-popup-else` and `m3.branch.changed-before-first-mutation`.
- **Artifacts**: run records showing the chosen arms.
- **Out of scope / escalate**: loops and workflow calls.
