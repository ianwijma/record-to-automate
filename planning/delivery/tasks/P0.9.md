# P0.9 Attended real-session check on X11

[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M0](../milestones/M0.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

Read [execution rules](../execution.md) and [safety invariants](../safety.md) before executing. Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. Follow linked dependencies for their contracts; execute only this packet.

- **Outcome**: human evidence on the actual Pop!_OS GNOME X11 session with the fixture only.
- **Depends on**: [P0.6](P0.6.md), [P0.8](P0.8.md).
- **Files**: `validation/cases/m0/manual-real-session.ts`, `validation/manual/m0.manual.real-session.md`.
- **Steps**: write an attended script in which the operator keeps their hands off unless prompted.
  1. Calibrate capture timing on this actual session and arm/test the independent abort route before input; Xvfb calibration is not transferable. Run a fixed replay on the fixture. The receipts must match.
  2. Run a slow 20-click replay. The operator presses the physical abort chord with the fixture focused, then repeats with a genuinely fullscreen fixture (verify its geometry/state; maximization is not fullscreen). There must be zero receipts after `ABORTED`, and `routes=chord`.
  3. The operator confirms the physical presses/releases and any unexpected input. Recording and non-target filtering attendance belong to [P2.8](P2.8.md), after [P0.7](P0.7.md) exists.
- **Contracts/errors**: refuses to run on Xvfb.
- **Acceptance**: `bun run validate --case m0.manual.real-session --attended` writes the evidence file. `bun run validate --suite m0` then exits 0.
- **Artifacts**: `artifacts/manual/m0.manual.real-session/<fingerprint>.json` and ledgers.
- **Out of scope / escalate**: Chrome and Last Z. A physical abort failure blocks M2's manual gate and is reported with the abort ledger.
