# P3.2 OCR read and find-text (Tesseract CLI)

[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M3](../milestones/M3.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

Read [execution rules](../execution.md) and [safety invariants](../safety.md) before executing. Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. Follow linked dependencies for their contracts; execute only this packet.

- **Outcome**: `readText(frame, area) → {text, words[]}` and a `text` locator with the four outcomes. A Read step stores a run-local value.
- **Depends on**: [P3.0](P3.0.md) (D-RECOG criteria and D-SEMANTICS run-local value choice only), [P3.1](P3.1.md) for Chrome cases. Pure OCR/fixture cases may start after [P2.7](P2.7.md).
- **Files**: `packages/vision/src/ocr.ts`, `packages/engine/src/locators/text.ts`, `packages/schema/src/workflow.ts` (`text` locator, `read` step, run-local value), fixture `text-*` scenes.
- **Steps**: crop, scale ×2, run `tesseract stdin stdout --psm 6 tsv`, and parse the boxes. Match using normalized equality with an approved normalization. Report a failed process as `Unavailable`, never as `Absent`.
- **Contracts/errors**: `E_OCR_UNAVAILABLE`.
- **Acceptance**: `m3.ocr.*` cases on the fixture and Chrome. A later G-R measurement uses [P3.4](P3.4.md) frames and the D-RECOG criteria; those live frames are not prerequisites for fixture OCR acceptance.
- **Artifacts**: TSV output and crops.
- **Out of scope / escalate**: other OCR engines, which go through D-RECOG.
