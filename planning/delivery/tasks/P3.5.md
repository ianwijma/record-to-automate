# P3.5 Steam launch probe

[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M3](../milestones/M3.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

Read [execution rules](../execution.md) and [safety invariants](../safety.md) before executing. Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. Follow linked dependencies for their contracts; execute only this packet.

- **Outcome**: launch acceptance, process appearance, stable geometry and visual readiness reported as separate stages.
- **Depends on**: [P3.4](P3.4.md); explicit authorization to launch the selected app, reused if already given.
- **Files**: `packages/engine/src/acquire/steam.ts` (probe-grade), `validation/cases/m3/steam.ts`.
- **Steps**:
  1. The user confirms the app ID locally.
  2. Run `xdg-open steam://rungameid/<id>`.
  3. Time each stage separately.
- **Contracts/errors**: one error per stage: `LaunchNotAccepted`, `ProcessNotSeen`, `GeometryUnstable`, `NotReady`.
- **Acceptance**: `m3.manual.steam --attended` (measure).
- **Artifacts**: stage timings.
- **Out of scope / escalate**: shipping timeouts (D-EXEC-Q).
