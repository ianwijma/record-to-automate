[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M4](../milestones/M4.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. Follow linked dependencies for their contracts; execute only this packet.

- **Outcome**: [board 04](../../design/journey.html#b04) and [board 11](../../design/journey.html#b11) bars over the target window, plus the red takeover frame. Keep overlays outside captured target pixels or use a measured exclusion method; register their controls as non-target recipients.
- **Depends on**: [P4.6](P4.6.md).
- **Files**: `apps/desktop/main/src/overlay.ts`, `apps/desktop/renderer/src/overlay/*`.
- **Steps**: prefer a bar just above the target when root capture would include it. Only decorative frame pixels are input-transparent; control windows receive input and are registered as non-target, so the guard rejects automation onto them. Do not ignore an overlay when computing the real recipient or assume root capture can subtract its pixels.
- **Contracts/errors**: none new.
- **Acceptance**: `m4.overlay.*`, including a dispatch point under the bar → `E_RECIPIENT`.
- **Artifacts**: screenshots.
- **Out of scope / escalate**: none.
