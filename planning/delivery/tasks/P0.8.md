- **Outcome**: measured guard-death behavior and dispatch expiry under an ordinary delayed diagnostic write. Production fsync comparison is deferred to [P6.0](P6.0.md).
- **Depends on**: [P0.6](P0.6.md).
- **Files**: `validation/cases/m0/faults.ts`, `scripts/validate/write-delay.ts` (test-only ordinary-write delay).
- **Steps**: add these measure cases.
  - `m0.fault.guard-sigkill-hold`: SIGKILL the guard while it holds button 1. Record whether the X server releases the button, using the fixture ledger and `xinput query-state`.
  - `m0.fault.slow-write`: delay between observation and submit longer than `permitValidityMs`. The guard must reject with `E_EXPIRED`, which makes this case a check, not only a measurement.
  - `m0.gl.latency`: 200 fixed actions, reporting the distribution of each G-L stage.
- **Contracts/errors**: none new.
- **Acceptance**: `bun run validate --case m0.fault.*,m0.gl.latency`.
- **Artifacts**: `sigkill-hold.json`, `gl-latency.csv`.
- **Out of scope / escalate**: fixing release after SIGKILL belongs to [P7.1](P7.1.md). The result feeds D-EXEC-E.
