- **Outcome**: a local HTML fixture with the same scenes, run in Chrome with a temporary profile. A test-only Bun ledger server on 127.0.0.1 records receipts.
- **Depends on**: [P2.7](P2.7.md). Temporary fixture profile on private Xvfb is within fixture scope; user-profile/live-page input remains D-TARGETS.
- **Files**: `fixtures/web-target/{index.html,scenes.js}`, `validation/lib/web-ledger.ts`, `validation/cases/m3/chrome.ts`.
- **Steps**:
  1. Launch `google-chrome --user-data-dir=<tmp> --no-first-run file://…`.
  2. Resolve the window by WM_CLASS plus a title token.
  3. Re-run the M1 and M2 e2e cases against Chrome.
- **Contracts/errors**: the window match must be unique, or the run stops.
- **Acceptance**: `bun run validate --suite m3 --case m3.chrome.*` (`missing` if Chrome is absent).
- **Artifacts**: ledgers.
- **Out of scope / escalate**: the user's own Chrome profile.
