# P0.0 Workspace and native toolchain

[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M0](../milestones/M0.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

Read [execution rules](../execution.md) and [safety invariants](../safety.md) before executing. Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. Follow linked dependencies for their contracts; execute only this packet.

- **Outcome**: an empty, buildable workspace. `bun install` and `bun run build:native` work, or report missing prerequisites precisely.
- **Depends on**: none.
- **Files**: `package.json`, `tsconfig.base.json`, `.gitignore` (`artifacts/`, `build/`, `node_modules/`), `native/build.ts`, `native/x11/host.c`, `native/x11/common/{log.c,log.h,harden.c,harden.h}`, `config/experimental.json`.
- **Steps**:
  1. Create a root `package.json` with workspaces `apps/*` and `packages/*` and the scripts `validate`, `build:native` (`bun native/build.ts`) and `test` (`bun test packages`).
  2. In `native/build.ts`, compile each binary target with `cc -std=c11 -O2 -Wall -Wextra -Werror -D_GNU_SOURCE -pthread` using only the modules the selected target needs (`x11`, `xtst` initially; `xext` only for an optional XShm path), writing to `build/native/`. Probe exact missing headers/modules; do not require XI2 before an actual use. Dependency discovery is bounded to one build attempt and one local fix/rerun, then report the named failure.
  3. Implement `harden.c` with `r2a_harden()`: `prctl(PR_SET_DUMPABLE, 0)`, `setrlimit(RLIMIT_CORE, 0)` with errors checked. Parent EOF triggers the guard’s normal abort/release path; do not kill the guard before it can release inputs.
  4. Write `config/experimental.json` with the values from [shared §2](../defaults.md).
- **Contracts/errors**: binaries are `build/native/r2a-x11-host` and the fixture `build/native/r2a-x11-target`. Host modes are `guard`, `capture`, later `observe`; a mode is a separate process, not three independently packaged helpers. Build only existing packet targets. A missing toolchain exits 2.
- **Acceptance**: bootstrap with `bun run build:native`; [P0.1](P0.1.md) then exposes `env.toolchain` and `env.xvfb` through `bun run validate`. No forward dependency on the not-yet-written validator.
- **Artifacts**: the compiler command line, `pkg-config` versions and `uname`/`xdpyinfo` summaries in `env.json`.
- **Out of scope / escalate**: installing packages. A missing toolchain is reported to the user.
