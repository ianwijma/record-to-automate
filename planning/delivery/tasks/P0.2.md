# P0.2 Host line protocol and clock types

- **Outcome**: one TypeScript codec and one C parser for protocol `R2A/1`, plus typed monotonic time.
- **Depends on**: [P0.1](P0.1.md).
- **Files**: `packages/host-protocol/{package.json,src/line.ts,src/time.ts,src/errors.ts,test/line.test.ts}`, `native/x11/common/{proto.c,proto.h,clock.c,clock.h}`, `validation/cases/m0/protocol.ts`.
- **Steps**:
  1. Define the line format: `<VERB> key=value key=value\n`. Values are percent-encoded and use only `[A-Za-z0-9._:-]` unencoded. A line is at most 4096 bytes, and the first line on each stream is `HELLO proto=R2A/1 role=<guard|capture|observe>`.
  2. `time.ts`: `MonoNs` is a branded `bigint`. `Interval` is `{earliest, latest}`. Functions: `parseMono()` and `widen(interval, ns)`.
  3. `clock.c`: `r2a_mono_ns()` uses `clock_gettime(CLOCK_MONOTONIC)`.
  4. Unit-test round-trips, oversize lines, bad escapes and unknown verbs. The case also round-trips 1,000 generated lines through a C echo mode (`r2a-x11-host --proto-echo`).
- **Contracts/errors**: error replies are `ERR code=<E_*> ref=<requestId> msg=<text>`. Codes: `E_PROTO`, `E_TOO_LONG` and `E_UNKNOWN_VERB`. The connection survives a bad line.
- **Acceptance**: `bun run validate --case m0.protocol.roundtrip,m0.clock.domain`. `m0.clock.domain` brackets the helper's `NOW` reply between two `process.hrtime.bigint()` readings across 200 samples, to show both use the same clock domain (it does not assume so).
- **Artifacts**: mismatching samples, and the distribution of bracket widths.
- **Out of scope / escalate**: JSON in C, and protocol versions beyond R2A/1.
