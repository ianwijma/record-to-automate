[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M8](../milestones/M8.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

Read [execution rules](../execution.md) and [safety invariants](../safety.md) before executing. Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. Follow linked dependencies for their contracts; execute only this packet.

- **Outcome**: a written Wayland contract for pixels, event-time recipient observation, dispatch, recipient verification, abort and release, for the D-PLATFORM-S candidate. Only cells with passing PW evidence get contracts. The others get a next-method proposal. D-PLATFORM-C records the intended support claim.
- **Depends on**: [PW.2](PW.2.md), [P7.1](P7.1.md), D-PLATFORM-S; D-PLATFORM-C and the Wayland D-EXEC-E amendment before final production contracts.
- **Files**: `docs/contracts/wayland.md`, `probes/wayland/*`, `validation/cases/probe-wayland/*` (only the named next-method probes).
- **Steps**: list every required cell, evidence, exact acceptance and dependency. For an open cell, specify one bounded next-method probe and run it under existing setup authority before finalizing that cell’s production contract. Permission/integration changes need explicit scope. A completed report with open cells does not satisfy the adapter prerequisite. Freeze named errors/files/tests for each adapter once evidence supports it.
- **Contracts/errors**: this packet defines them. No final contract may be invented without evidence.
- **Acceptance**: `decision.wayland-contract` checks D-PLATFORM-C and the Wayland execution amendment; each adapter’s required cell evidence must pass before its contract is executable. Unresolved cells remain missing.
- **Artifacts**: none.
- **Out of scope / escalate**: compositor extensions or brokers without approval.
