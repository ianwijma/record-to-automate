# P2.5 Renderer: minimum journey pages

[Delivery index](../../DELIVERY-PLAN.md) · [Milestone M2](../milestones/M2.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Requirement and W-package mapping](../coverage.md)

Consult [experimental defaults](../defaults.md) for implementation constants and [validation contract](../validation.md) when implementing or running acceptance cases. Follow linked dependencies for their contracts; execute only this packet.

- **Outcome**: a user can pick the fixture window, record, review steps, edit one action's target, save, reload, run, pause or stop, and read why a run stopped.
- **Depends on**: [P2.4](P2.4.md).
- **Files**: `apps/desktop/renderer/src/pages/{Library.tsx,NewRecording.tsx,Recording.tsx,Review.tsx,EditAction.tsx,RunPrep.tsx,Running.tsx,Stopped.tsx}`, `apps/desktop/renderer/src/components/{ScreenshotMarks.tsx,StateLabel.tsx,LockRow.tsx,RunBar.tsx}`, `apps/desktop/renderer/src/state/store.ts`.
- **Steps**: each page follows its board, reduced to M2 scope.
  1. [Board 16](../../design/journey.html#b16) Library: cards with "Open workflow", plus an empty state.
  2. [Board 03](../../design/journey.html#b03) New recording: window picker, a window-only preview with a blue outline, and Start disabled with a reason when no window matches.
  3. [Board 04](../../design/journey.html#b04) Recording: an in-app bar with Pause, Stop and the abort chord shown as text. The overlay bar comes in [P4.7](P4.7.md).
  4. [Board 05](../../design/journey.html#b05) Review: only recorded steps, in plain sentences. Require explicit acceptance of proposed targets; a passing self-test alone does not make a draft runnable.
  5. [Board 06](../../design/journey.html#b06) Edit action: a method choice of Fixed or Picture; for Fixed, move the point on its screenshot; for Picture, drag the search-area rectangle with handles and confirm the proposed target; Preview only draws; Save increments the revision in the plain document.
  6. [Board 10](../../design/journey.html#b10) states A, B and C.
  7. [Board 11](../../design/journey.html#b11): an in-app run bar labelled "App in control · hands off".
  8. [Board 12](../../design/journey.html#b12): stopped, showing expected versus seen and "nothing clicked" when `dispatched:false`.

  Results use only the four answers (Found one, More than one, Not found, Couldn't check), never a score.
- **Contracts/errors**: the renderer holds no file paths. Assets load only through `r2a-asset://<handle>`.
- **Acceptance**: covered by [P2.7](P2.7.md) end-to-end cases, plus `m2.ui.no-scores` (a DOM scan for `%` or numeric scores in result labels).
- **Artifacts**: Playwright screenshots of each page state.
- **Out of scope / escalate**: Flow and Values tabs, copy, and the full visual polish of the boards ([P4.6](P4.6.md)). If a board conflicts with M2 scope, follow the board and leave the control disabled with an "Available in a later preview" label. Do not invent new UI.
