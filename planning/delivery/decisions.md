# Choices needed at their point of need

[Delivery index](../DELIVERY-PLAN.md) · [Implementation plan](../IMPLEMENTATION-PLAN.md)


Only unresolved user-owned choices stop their dependent behavior. The executor records the answer and its source; existing session authorization remains valid without another request or a user-created file. Framework/binding/fixture tuning within an experiment is an implementation choice, not a new approval ritual. Production gates inherited from the implementation plan remain applicable.
