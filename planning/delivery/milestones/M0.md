# M0

[Delivery index](../../DELIVERY-PLAN.md) · [Implementation plan](../../IMPLEMENTATION-PLAN.md) · [Coverage](../coverage.md)

**Gate.** [P0.6](../tasks/P0.6.md) registers M0 as the default runnable automated milestone. It must execute real fixed clicks and rejection/abort cases on Xvfb. [P0.8](../tasks/P0.8.md) adds fault cases when implemented. `--suite m0` also requires [P0.9](../tasks/P0.9.md)’s attended evidence and returns 2 while that is missing. Missing attendance does not block M1 or the M2 shell/store. Passive recording [P0.7](../tasks/P0.7.md) belongs to the M2 recording prerequisites, despite its stable P0 identifier.
