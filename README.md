# Record to Automate

A planned open-source desktop application for recording, editing, running and debugging desktop automations. Linux comes first, with X11 and Wayland support to be qualified. The application is not implemented yet.

- **[Selected visual journey](planning/design/opus/journey-v2.html)** — Opus's sixteen-board design, chosen after mutual review and revision.
- **[Design document](planning/design/opus/design-v2.md)** — the selected visual language, pages, states and rationale.
- **[Implementation plan](planning/implementation/IMPLEMENTATION-PLAN.md)** — architecture, feasibility gates, work packages and release evidence.
- **[Product decisions](planning/DECISIONS.md)** — confirmed requirements and choices still open.
- [Planning index](planning/README.md).

Clone the repository and open the selected journey or [visual overview](planning/design/opus/overview-v2.html) locally. Their bundled screenshot loads without a server or network. The mockups are static design references and perform no automation.
