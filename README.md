# Record to Automate

A planned open-source desktop application for recording, editing, running and debugging desktop automations. Linux comes first, with X11 and Wayland support to be qualified. The application is not implemented yet.

- **[Visual journey](planning/design/journey.html)** — the selected sixteen-board application design.
- **[Design document](planning/design/DESIGN.md)** — visual language, pages, states and rationale.
- **[Implementation plan](planning/IMPLEMENTATION-PLAN.md)** — architecture, feasibility gates, work packages and release evidence.
- **[Product decisions](planning/DECISIONS.md)** — confirmed requirements and choices still open.
- [Planning index](planning/README.md).

Open the journey or [design overview](planning/design/overview.html) locally after cloning. Their bundled screenshot loads without a server or network. The static mockups perform no automation.

Historical planning material is preserved in `.archive/planning/`. Active work uses the documents linked above.
