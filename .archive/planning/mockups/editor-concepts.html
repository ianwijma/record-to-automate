Try this

  • Click any step in the flow (A) or outline (B); the selection is shared, so switching concept keeps it. Open Open rewards menu to see its recording timeline.
  • In Recording, select a click and switch its target between fixed point, text, image and Jev. The search area, target and click point are separate controls. “Test on current screen” only looks, it never clicks.
  • Tick steps 2–3, choose Re-record selected, then review the replacement: reward_count loses its source. Accept, Discard and Undo work.

Choices made only for this demo (not decided)

  • Start defaults to “use the window that's already open”. Steam launch is shown as a candidate with no game picked.
  • “Couldn't check” and “Gave up” are separate from No and are left unconnected. What should happen there (stop, retry, ask) hasn't been decided.
  • Values made on only one branch are marked as such after the paths rejoin. Whether they're kept for this run, globally, or saved to a file hasn't been decided.
  • Jev is shown as an opt-in, online method for checks and targets, next to local text/image matching. Claude Code / Codex appear only under Assist, for help while editing. How much they do at first is still open.
  • Calling another workflow is left out on purpose: branches here just pick different actions inside the same workflow.
