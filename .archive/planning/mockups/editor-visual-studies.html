What this study assumes (not decided)
  • Only one real screenshot exists, so only Click “Mail” shows a frame. The other steps say there's no frame.
  • Mail's bounds, its safe area and the badge exclusion are drawn by eye from that screenshot. They aren't a measured hitbox. Coordinates count from the game window's top-left corner, using this screenshot's estimated title bar and borders.
  • “Vary inside a safe area” only changes where the click lands. There are no timing controls. Waits like “Wait until ready” are separate checks and work as before.
  • A fixed-position click stays on its recorded point unless you set a safe area yourself.
  • When the target is missing or unclear, nothing is clicked. What happens next (stop, retry, ask) is still undecided.
  • Jev is optional, online and experimental, and is set per step. Claude Code and Codex appear only under Assist, to help while you edit.
